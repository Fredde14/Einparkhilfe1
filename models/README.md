# 🚗 KI Parkassistent (Smart Parking Guide)

Ein KI-gestütztes Assistenzsystem für Parkmanöver, entwickelt als Informatikprojekt (12. Klasse). Die App analysiert Bilder von Parklücken mithilfe von Computer Vision und Machine Learning (YOLOv8) und gibt auf Basis der individuellen Fahrzeugmaße maßgeschneiderte Einpark-Anleitungen.

## 🌟 Highlights
- **Homebildschirm-Setup:** Manuelle Konfiguration der Autolänge, Autobreite und des Parktyps.
- **Machine Learning Integration:** Objekterkennung (YOLOv8 & OpenCV) zur Erkennung von Begrenzungsfahrzeugen.
- **Interaktiver Guide:** Dynamische Berechnung der Parklückeneignung inklusive Schritt-für-Schritt-Trajektorie.
- **Professionelles UI:** Modernes Design mit Custom-CSS und responsivem Workflow.
